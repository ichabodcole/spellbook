# Polish before the release

## Why now

The workspace stack is finished. [The cutover](2026-10-cutover.md) closed on
2026-10-22 with the kit Scriptorium as Scriptorium. `develop` is about 500
commits past `main`, so the next release is a large one. The cycles that got
here, and Cole's trial of the flipped build, left a pile of small items under
[Workspace Kit follow-ups](../features/workspace-kit-follow-ups/feature.md).
This cycle clears the small ones a user would meet, so the release ships without
them. Anything that needs design waits.
