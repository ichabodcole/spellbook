## The one unknown, and how it went

The brief's expected layout — `components.json` + a per-spell tsconfig, no
manifest — fails one hard check: `add`'s preflight wants `cwd/package.json`.
Measured in the scratchpad (five `measure-*` trees), reported, ruled: workspace
member + hoisted pin. The alias half of the expectation was right and is now
measured fact: Bun's runtime and bundler honour the nearest tsconfig's `paths`
per importing file, so every spell can carry the same `@/*` without colliding.
