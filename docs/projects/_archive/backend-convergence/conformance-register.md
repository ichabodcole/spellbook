# MOVED — the conformance register now lives in `docs/architecture/`

**Moved 2026-09-10** (decision **D92**) to
[`docs/architecture/house-conformance-register.md`](../../architecture/house-conformance-register.md).

**Why, in one line:** it is a house-conformance inventory spanning eight spells
with thirty-five rows still open, not a project artifact — and archiving this
project would have buried every one of them.

This stub exists so that a reader arriving at the old path from a journal, a
brief or a commit message is not left with a 404. **Do not append rows here.**
Everything — the fix-now-versus-defer rule, sections A through F, and the closed
rows kept struck through rather than deleted — is at the new path, unchanged
except for the header.

⛔ **Two rows in particular were the reason for the move: B1 and B2, the epoch
parameter.** This project's proposal excluded epoch resume **by name**, as a
dependency it would not discharge rather than something to smuggle into the
roll. A dependency a project declared out of scope does not belong in that
project's archive.

- [`docs/architecture/spell-backend-architecture.md`](../../architecture/spell-backend-architecture.md)
  — the shape each spell HAS, where the register records where the eight do not
  yet agree.
- [`./decision-log.md`](./decision-log.md) — D92 carries the relocation and the
  options not taken.
