## What was driven, and what was not

The whole inventory was driven against a **release** daemon at the local-sim
destination (a copy of `git ls-files plugins/spellbook/skills/bounty` with no
`node_modules` up-tree) and a **dev** daemon in the repo. 62 rows `release`, 10
`both`, 21 `test`, **17 `not: <why>`**.

Both MCP browser servers were down for this session, so the drive is ~70 lines
of Bun over raw CDP — the user's Chrome launched `--headless=new` with
`--remote-debugging-port`, attached via `/json/list`, `Runtime.evaluate`. No
playwright, no puppeteer, nothing installed. The instrument that mattered most
was **`Page.addScriptToEvaluateOnNewDocument` installing a `window.WebSocket`
shim before the page loads**: it is the only way to see a socket the surface
never exposes, and it turned every "sends nothing" row from an inference into an
assertion.

**The seventeen `not:` rows are claims a verifier will run.** Four are honest
instrument limits and are the ones worth a real pointer and a real clock: a
`dataTransfer.setData` throw (D4), a real `dragend` on an aborted drag (D14), a
frame arriving inside a live pointer sequence (D16), and the two wall-clock
timers (K12 / T4 / X1 / X2). The rest say "the property now holds by
construction", which is exactly the shape of claim a no-stake agent should
disbelieve.

## Two regressions this branch introduced and fixed

Both were found by the author's own drive, both are in the class R8 names — an
interaction the author's model says is atomic and the browser does not — and
**neither was findable by reading the code.**

1. **Two filter chips clicked inside one tick lost a toggle.** Both handlers
   read the same render's `filters` closure and the second discarded the first.
   **The Alpine page could not have this defect**: it mutated the arrays in
   place. Same shape as grapevine's focus regression. Fixed with a functional
   update, with the persist riding the same call.
2. **Two columns could be lit at once mid-drag.** The old page ran
   `clearDropMarkers()` **board-wide on every `dragover`**, so at most one
   column was ever highlighted whether or not a `dragleave` arrived. Per-column
   state made the highlight depend on `dragleave` firing. Fixed by making the
   drop hint one piece of board state.

## Three findings that outlive the branch

1. **A test file under `surface/` changes the shipped stylesheet.**
   `@source "./"` scans the directory whole. Moving one source-scanning test
   into `src/bounty/surface/` changed the built sheet's content hash; moving it
   up one level restored it exactly. Filed:
   `docs/backlog/2026-09-06-surface-tests-pollute-the-shipped-stylesheet.md`.
   **Grapevine has four tests under `surface/` today.**
2. **`spell-css-scope` was carrying a latent defect** that only an arriving
   spell could expose: Tailwind's `group`/`peer` marker classes read as
   cross-spell leaks for any spell that uses the variants and never spells the
   bare word. Amended with a two-name exemption and a cell pinning its
   membership.
3. **A daemon can die correctly and say nothing.** `server.ts`'s
   `uncaughtException` handler logs to a file and never touches stderr — right
   for a mid-flight fault, and it swallowed the forced-dev import failure whole
   (exit 1, no output, reads as "bun is missing"). The dev import now has its
   own catch. **Any spell with a fatal handler will have this.**

## After the verify pass

An independent no-stake agent drove the whole inventory. **No severe
regression** — the two defects the author's own drive caught (the filter
double-toggle, the two-lit-columns) hold up under a real pointer and real
double-clicks. It drove **thirteen of the fifteen `not:` rows**, and found two
things the author did not. Both are fixed on this branch:

1. **`ended` did not reach portalled content (P7) — the one that could not
   land.** `DialogContent` / `AlertDialogContent` portal to `document.body`,
   outside the `#root` wrapper carrying the class. An open modal after session
   end measured `pointer-events: auto`, `opacity: 1`,
   `closest("#root") === null`: bright, fully clickable, over a dead grey board
   — and its Save button accepted the click and sent nothing. No state diverges
   (`send()` is already a no-op); the affordance lies, which is worse. **Fixed
   by putting the class back on `<body>` where the old page had it**, as a
   hand-written `.board-ended` rule rather than two utilities — measured en
   route: Tailwind's scanner did not extract the utility names from a JS string
   array, so the first fix shipped with neither rule in the sheet and was
   silently inert.

   **Driven after the fix, release, at the local-sim destination:** dialog is
   outside `#root` and inside `<body>`; body carries `board-ended` with
   `opacity 0.6` / `pointer-events: none`; the dialog's computed
   `pointer-events` is `none` by inheritance and so is the Save button's;
   `elementFromPoint` at the centre of Save returns `HTML` — no pointer can
   reach it; the board columns are inert too. Parity with the old page restored.

2. **The notes clamp was dead (K17).** Found by re-driving the observation the
   row actually asks for. `line-clamp-2` is a **display** utility and a `block`
   beside it won the tailwind-merge conflict, so `clientHeight === scrollHeight`
   and a four-line note rendered in full. The class list reads correctly; only
   the box does not. Fixed and re-measured (`clientHeight 37` against
   `scrollHeight 131`).

**The failure mode both share is the Driven column's own**: a cell that records
an observation _adjacent_ to the one its row demands. The verifier flagged it in
M2 and D5; sweeping for the pattern found it in ten more cells, and one of those
was defect 2. Every instance has been re-driven and now records a measurement
rather than a bare `visual` / `both`.

**Records corrected, not just appended to.** The coverage table was wrong in
three of four columns (110/62/21/17 by eye, against 115/80/15/15 by command) and
is now derived by a script that reports unparsed cells and duplicate ids. The
L-table cited `server.test.ts` as the guard for the blocker predicate and that
file contained neither name — `liveBlockerCount` being a primitive **this branch
created**; eight cells now exist, calibrated red. Three unrowed behaviours added
or recorded: a frame arriving while the human is typing (W16 — holds on all
three text surfaces, caret intact), and modal focus containment plus whole-card
keyboard reachability as departures 6 and 7, because a silent improvement is
still a behaviour difference.

**Promoted to the playbook (R8)**, where an agent building an instrument will
meet them: React 19 maps `onBlur` to `focusout`; a controlled input needs the
prototype's value setter; `DataTransfer.prototype.setData` is patchable from an
init script; a live socket's `send` can be neutered with `readyState` left OPEN;
a `window.WebSocket` shim installed before page load is cheaper than the proxy
for everything except a real transport drop; a Driven cell that answers an
easier question is a green hiding a miss; count the column by command.
