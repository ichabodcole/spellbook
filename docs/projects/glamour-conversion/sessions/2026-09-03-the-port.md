## The decisions, and the options not taken

**Phase 1 and Phase 2 each landed as ONE atomic commit.** The alternative — the
surface half lands, the backend half follows — leaves the moved symbols in both
files in between, which is the state where nothing in this repo distinguishes a
move from a copy. The clause-1 cell added the same day makes the alternative
_fail_: glamour joins `roster()` the moment `src/glamour/surface/index.html`
exists, so a split Phase 2 reds on its first commit. **A prose ruling became a
gate.**

**`reduce.ts` split rather than moved whole.** Measured at the symbol grain: 21
backend exports, 4 pure selectors, intersection zero. Shipping it whole would
have handed the surface 21 backend exports it must never call — the
misfiled-`.server` defect this port existed to fix, mirror-imaged. circe argued
for `shared/reduce.ts` whole; ruled split on daedalus's own argument.

**Phase 3 — building the backend — was DROPPED, then re-answered after the acc
work and dropped again.** Structural benefit is zero (glamour's shipped backend
imports only `node:` builtins and its own relative paths), and Contract 3's
repeal is enumerated. What changed: glamour now clears the acc gate, so it is
**eligible** rather than permitted. The trigger's wording was corrected from
"glamour decides" to "the roster rules on convergence." _Superseded by Cole's
ruling after this session: **if code is shared between spells, there is a build
process** — skills must deploy self-contained, so a shared module outside the
skill folder simply fails at a direct install. Vendoring would satisfy
deployment and not divergence. That ruling replaces Contract 3's enumeration
with a criterion and is the first commit of the follow-on project, not a code
move._

**acc L0 ran BEFORE the port**, as its characterization harness. That ordering
is the only reason the empty rule-by-rule diff means anything: run acc after a
relocation and a pass cannot distinguish "the port changed nothing" from "the
port changed something acc never saw."

## What the port found that was not about glamour

- **Contract 5's documented failure mode is false.** "Tailwind silently skipped,
  the board renders unstyled" — measured, the page fails with a 500 and no
  stylesheet link. The sentence had propagated unmeasured through five spells'
  comments, the playbook, a lane, three rulings, and into this port's own first
  draft. Corrected in all seven places.
- **A comment edit to a BUILT backend is not docs-only** — the bundler strips
  the comment from the code and keeps it in the sourcemap, so a reword moves
  `dist/cli.js`. Found by a guard its author built against a hazard he did not
  believe he had.
- **A symlinked-`node_modules` worktree is not Contract 18's canonical checkout
  root.** Tests there are sound; builds are not.
- **The consumer path is not the unit path.** `release-serve` asserts on
  `server.ts`; every consumer goes through `cli.ts`; they disagreed, and the
  consumer got an ENOENT blaming `bun` for a missing directory.
- **`PROJECT-SUMMARY.md` said "four spells build"** — a grounding doc every seat
  reads, in no seat's scope, stale for the second time in the same way.
