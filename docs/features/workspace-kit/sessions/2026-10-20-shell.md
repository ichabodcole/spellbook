# The shell

## Context

This was the fifth Workspace Kit cycle. A survey on 2026-10-19 split the
workspace stack's last cycle in two: this one, the shell with the flag still
off, and the cutover after it ([cycle](../../../cycles/2026-10-shell.md),
[port shape §2b](../../../items/workspace-stack-port-shape/write-up.md#2b-the-cycles)).
Cole approved the cycle, its eleven items and six rulings in a Scriptorium
review, and noted that Story Studio's idea of a project and its file tree is
diverging from Scriptorium's. Every Story Studio commit was judged against
Scriptorium's model for that reason. The branch was `cycle/shell`.

As before, every item was built by a subagent in its own worktree, checked by a
verifier with no stake in it, sent back until it held, and cherry-picked with
its fixups folded in. Dist was rebuilt once after each pick.

## What Happened

**The port.** Story Studio's shell came from `develop` at `7832083`, cut back:
five commits reversed (copy-in, the plugin host, Atlas stage drops, the
workspace heading, entering a folder as the root) and two cut by hand (the
blocking workspace prompt, copy-in). A guard test fails if a workspace prompt or
heading ever shows for an app with no home workspace. Its first version caught
only the exact words it named; the verifier's mutations widened it.

**The items, in the order they landed on `cycle/shell`:**

1. `kit-port-shell`, with the shell's own stylesheet (`theme/shell.css`), since
   scanning it from `base.css` grew every other spell's CSS.
2. `test-stubs-bind-loopback`, out of turn (below).
3. `kit-mdx-documents` (basic `.mdx`, ruling 1) and
   `kit-legacy-sets-show-sessions` (a scan guard and a restore that drops or
   narrows a set holding Scriptorium's own folders).
4. The CLI contract: `kit-ended-session-hint`, `kit-workspace-cli-hints`,
   `kit-add-folder-literal-tilde`, `kit-discovery-pointer-hardening`. Rebuilt
   once as four clean chapters so each could be picked alone.
5. `scriptorium-kit-keepers` with `meta-set-byte-safety`: the kit path borrows
   nothing from the shipped code, has its own stylesheet, and every frontmatter
   reader on both paths agrees on a byte-order mark and a quoted first key.
6. `kit-shell-storage-slot` and `kit-shell-sidebar-slots`.
7. `kit-watcher-frontmatter-edit-no-broadcast`, with a 2 s cap so a steady
   trickle of changes can't starve it.
8. `kit-second-tab-misses-edits`, with coalesced redraws and positions mapped
   across a held redraw.
9. `scriptorium-kit-shell`: the flagged Scriptorium in the shell, prefs-backed
   layout, End session's unsaved warning, ⌘S in every view.
10. `set-make-relink-offer`, `kit-broken-links-visible`.
11. The Atlas comparison, then `kit-composer-closed-waiting-mark` (C6) and
    `kit-stalled-note-ask-act` (C7), which Cole took into the cycle from it.

**Rulings made by the lead during the cycle** (the wire and agent contract,
which are the team's to rule):

- A verb with no `--session` targets the newest session, live or not, and never
  silently reaches another. "Newest" is a `last-opened.json` record the daemon
  writes at start; an untrusted record refuses rather than guesses.
- The shell's own stylesheet instead of a `base.css` entry.
- One fact, one meaning for frontmatter: every reader on both paths agrees.
- A refusal is always visible: toasted while the context column is collapsed.
- Broken links: "leaving the set" is opt-in for an app (Story Studio's default
  is unchanged), and leaving matches the shipped map for nested sets and for
  documents added on their own.
- With no agent listening, a stalled note offers no Ask (call C3); an asked note
  still says it was asked.

## Notable Discoveries

- **The test suite could reach the user's running daemons.** A verifier saw a
  test print a live Story Studio daemon's state. On this Bun, `Bun.serve` with
  no hostname listens on IPv6 only, so a real daemon holding the same port on
  IPv4 `127.0.0.1` took the CLI's connection. One such cell sends
  `version-new --doc x`, a write. Five test servers were bound to `127.0.0.1`, a
  ward now fails any `Bun.serve` without a host, and Cole had the fix put on
  `develop` at once (`15938f87`). Full gates were held until then; several had
  run before the hold.
- **The shipped Scriptorium never relayed a second tab's edit.** The item said
  it did within 500 ms; two verifiers showed it doesn't. The kit path now does
  better than the shipped app here.
- **The kit renderer is as slow as the shipped one, not slower.** One render of
  a 5k-line document with 3.5k links costs about 5 s in both. Coalescing stops
  the pile-up; the render itself is filed.
- **A "dead" check was not dead.** A verifier showed the same-set check a
  builder removed still decided leaving links for documents added singly.
- **Every verifier found something its builder couldn't.** Of nineteen items,
  every one went back at least once.

## Changes Made

- **The kit:** `src/kit/shell` (ported, with `theme/shell.css`, a storage slot,
  the panes' slots, an End-session warning slot, the rail's waiting mark and the
  notes' Ask act); a document-kind registry; a scan guard for an app's own
  folders; the CLI's session routing and pointer hardening; the edit relay with
  coalesced redraws and position mapping; the watcher's app-view refresh;
  `set.make`'s relink offer; the link check grouped by set.
- **The flagged Scriptorium:** runs in the shell, keeps its prefs in the daemon,
  borrows nothing from the shipped code, declares `.mdx`, a launcher and
  `linkCheck: { leaving, noun }`.
- **The shipped Scriptorium:** behaviour unchanged except `meta-set` byte safety
  and reading a byte-order mark's frontmatter, both deliberate fixes on both
  paths.
- **Tests:** a loopback ward, a kit-path import ward, and a guard against the
  single-workspace UI.

## Review

Each item was verified by a no-stake `general-purpose` agent with full tools,
which ran its claims: real browsers beside the shipped app, mutation tests,
parity harnesses, acc, and the full gate. Read-only reviewers were not used,
because the work needs browsers and daemons. Two verifiers broke a rule (`pkill`
on their own scratch path, and tests run before the scratch-HOME rule reached
them); the briefs were tightened each time.

The final gate on `cycle/shell` is recorded in the cycle's Outcome.
