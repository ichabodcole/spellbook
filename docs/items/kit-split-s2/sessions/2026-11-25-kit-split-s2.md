## Context

The first step in lane A. `session.ts` was 9,072 lines (Biome's count 7,848).

so the later steps have somewhere to import from that is not the facade.

## What Happened

- **Six parts** in `src/kit/workspace/session/`: `errors.ts` (45 lines),
  `names.ts` (166), `paths.ts` (143), `facts.ts` (201), `types.ts` (242) and
  `manifest.ts` (191). `session.ts` imports from them and re-exports the same 41
  names it exported before, types included; `index.ts` and every caller are
  untouched. Names that were private but that `session.ts` still uses gained
  `export`.
- **One way only.** `errors` uses a type from `types`; `names` uses `errors`;
  `paths` uses `names` and `errors`; `manifest` uses `errors` and `types`. No
  part imports `session.ts`. The tier test's table now lists all six at tier 0.
- **One departure from the write-up's map.** `tilde` and `entryAt` went to
  `names`, not `paths`: `copyName` in `names` uses both, and `paths` needs
  `names`, so the map's placement would have been a cycle. It is Story Studio's
  own tier 0 lesson; the architecture page records ours under it.
- **What stayed.** The note guard (`noteGuard`, `loadNoteGuard`, `guardLoaded`)
  and `placeNote` belong to the `notes` part (S7). `noteGuard` is the only
  module-level `let`, so no mutable state moved.
- **Names the map doesn't list** were placed by use: `isFolder`, `rootReal`,
  `shownOverlap`, `movedPairs` in `paths`; `randHex` and the copy-name constants
  in `names`; `TASK_NEXT`, `ContextIndex` and the plan types in `types`;
  `OUTWARD`, `MOVES_KEPT`, `keptOutside` and `IMPORT_NAMES_MAX` in `facts`.
- **The override** is 7,210 (was 7,848), the exact count.
- `docs/architecture/workspace-session.md` marks tier 0 built. The gate's build
  rebuilt the scriptorium server bundle (`chore(dist)`).
