# session.ts's core (S3) — 2026-11-25

[feature/kit-split](../../../features/kit-split/feature.md).

## Context

Tier 1, the core every later part takes, and the widest diff of the split:
`this.m` becomes `this.core.m` at about 200 sites. It ran alone, after W2
landed. `session.ts` was 8,265 lines (Biome's count 7,210).

## What Happened

- **Three parts, three commits.** `state.ts` (142 lines), `places.ts` (525) and
  `writes.ts` (86), one commit each, each passing typecheck, the tier test and
  the named tests on its own, each lowering the override to its commit's exact
  count: 7,210, 7,180, 6,794, 6,768. The staged result was diffed against a
  single-pass version of the same move: identical.
- **The shape.** The facade builds `core = new State(…)`, then
  `places = new Places(core)`, then `writes = new Writes(core, places)`. Each
  part takes `core` in its constructor and reads the record as `this.core.m`.
  Public members that moved keep a one-line delegate on the facade, so callers
  are untouched; private ones are called on the part directly. `State.persist`
  runs an `addToRecord` hook list, empty until a later part adds to the record.
- **Departures from the write-up's map,** each by dependency direction:
  - Into `state`: `own`, `realDir`, `pinDir`, `dirStillOrDie`, `refuseWrite`,
    `appHome`. `persist` needs them, and `state` cannot import `places`.
    `setAppHome` (the `workspace` part, S8) stays on the facade and sets
    `core.appHome`.
  - Into `places`, unlisted: `isWorkspace`, `workspaceOrDie`, `namedAsContext`,
    `itemAt`.
  - Left in `session.ts`: `writeShown` (needs `context`, tier 2); `adoptActive`,
    `writeActive`, `preserveOutside` (need `documents`, tier 3).
- **The ledger is private to `writes`.** `owned` and `ownBundles` are no longer
  reachable from the facade; its other ledger writes go through
  `writes.own(path, text)`, `writes.disown(path)` and
  `writes.isOwnBundleEcho(bundle)`, each doing what the old line did at the same
  site. This is the one change beyond the mechanical ones.
- **Tests.** `ownPlaces.test.ts` repointed from `m.docs` to `core.m.docs`, the
  only test change. `manifest.test.ts` replaces `s.persist` to count writes; no
  tier 1 part calls `persist`, so it still sees every call.
- `docs/architecture/workspace-session.md` gains "The core (tier 1, built at
  S3)". The gate's build rebuilt the scriptorium server bundle (`chore(dist)`).
