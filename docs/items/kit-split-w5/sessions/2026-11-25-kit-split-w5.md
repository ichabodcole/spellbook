# WorkspaceShell's right column (W5) — 2026-11-25

Part of [Split the kit](../../../cycles/2026-12-kit-split.md), step W5 of
[feature/kit-split](../../../features/kit-split/feature.md).

## Context

The last step in lane B, run beside S6. `WorkspaceShell.tsx` was 1,385 lines
(Biome's count 1,217), the last shell file over the 1,200 limit.

## What Happened

- **Two hooks.** `useRightColumn.ts` (273 lines) holds the notes, tasks and
  composer state, from `const notes` through `composerProps`; it takes 18
  ShellBody bindings and returns the 19 its callers use. `useRightTab.ts` (28)
  holds the chosen tab: it takes `storage`, `tabs` and `showChatTab`, and
  returns `setPanelId` and `activePanel`. Both bodies are byte-identical to
  develop, and both are called where their blocks sat, so ShellBody's 33 hooks
  keep their order.
- **Two files, not the three the item named.** There is no `rightTabs.ts`: the
  section holds no pure tab definitions. The tabs array is built from JSX on
  every render (labels carry `WaitingDot` and `Spinner`, each `node` is a panel
  closing over ShellBody's state), and the parent hands it to `ChatColumn`, so
  the panels' JSX stays in `ShellBody` between the two calls. The one constant,
  `TAB_KEY`, moved as a local of `useRightTab`. A data-only `rightTabs.ts` may
  arrive with [kit-icon-tabs](../../kit-icon-tabs.md).
- **The override is gone.** `WorkspaceShell.tsx` is 1,228 lines (Biome 1,064),
  under the default limit; its block is removed from `biome.json`, and the lint
  passes without it. Nine imports the moved code used went with it.
